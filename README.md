Worten Resolve — Códigos Técnicos

📌 Sobre o projeto
Este projeto foi desenvolvido para a Worten Resolve, com o objetivo de facilitar o trabalho diário dos colaboradores, reunindo num único local códigos técnicos, artigos, serviços e ferramentas úteis.
A plataforma permite pesquisar rapidamente informações relevantes para o atendimento ao cliente e para os procedimentos realizados em loja.

🎯 Objetivo
Tornar o trabalho mais simples, rápido e organizado, permitindo aos colaboradores encontrar a informação de que precisam sem perder tempo a consultar várias fontes.

⚙️ Principais funcionalidades
Pesquisa de artigos: pesquisa por nome, marca, equipamento, SKU ou EAN.
Códigos técnicos: consulta de artigos e serviços organizados por categorias.
Calculadora de Vendas: apoio ao cálculo de valores, descontos e subscrições.
Venda de Ecrã: ferramenta de apoio à apresentação e cálculo de preços para o cliente.
Películas: modo de consulta e apresentação das opções disponíveis.
Guia Rápido: instruções e procedimentos úteis para diferentes serviços.
Atalhos úteis: acesso rápido a ferramentas e plataformas de trabalho, como SalesTool, Processos, Seguros, Help Desk e outras.

👥 Para quem se destina?
Esta plataforma destina-se principalmente aos colaboradores da Worten Resolve, servindo como ferramenta de apoio ao trabalho em loja e ao atendimento ao cliente.

💡 Filosofia do projeto
A ideia é simples: menos tempo à procura de informação, mais tempo a ajudar o cliente.
O projeto procura centralizar informação útil, simplificar tarefas e melhorar a eficiência do trabalho diário na Worten Resolve.

🛠️ Desenvolvimento
Projeto em constante evolução, com atualização de artigos, categorias, ferramentas e funcionalidades de acordo com as necessidades identificadas.
